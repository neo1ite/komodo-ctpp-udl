# komodo-ctpp-udl
Basic UDL files for the CTPP2 template engine (with Underscore templates support). Includes built XPI extension for Komodo-Edit and Komodo-IDE

Just install the latest .xpi file in your Komodo installation

To build (assuming Komodo-IDE in ~/Komodo-IDE-9), run

    ~/Komodo-IDE-9/lib/sdk/bin/koext build

in project directory.
